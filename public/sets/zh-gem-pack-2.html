No English version

This one never left

Gem Pack Vol. 2 looks to be a regional exclusive. There is no English set to compare it to and no Japanese one either: its set code returns nothing under Japanese, Korean or Traditional Chinese on TCGdex, which is where we checked. If you want these cards, imported Chinese packs are the way.
