What is the code card in the pack?

You get one in every booster pack, and it is the only card in there nobody keeps. Here is the free official game it opens, Pokemon TCG Live, what the code actually gets you, and the part almost everybody has wrong about it.

Checked against Pokemon's own pages on August 16, 2026.

What is it What the code gives Our own count Redeeming it Getting the app What is different Live or Pocket First week Is it worth anything

So what is this thing?

Pokemon TCG Live is the official video game version of the Pokemon card game. It is free, it plays by the same rules as the cards on your table, and every booster pack you open comes with a code for it. It replaced Pokemon TCG Online, which was switched off on June 5, 2023; Live launched worldwide on June 8, 2023.

None of which is why you are here. You are here because there is a card in the pack that is not a Pokemon card, it has a long code and a QR square on it, and it goes straight in a pile. This page is about what that pile is for.

What the code actually gets you

Start with the thing almost everybody has wrong, in Pokemon's own words.

The digital booster pack will not necessarily contain the same cards as the physical booster pack from which you received the code.

Pokemon's own Code Card Redemption FAQ, read August 16, 2026.

So the digital pack is not a copy of the pack you just opened. It is its own pack from the same set, and pulling a hit does not hand you a second one.

  • A deck code is the exceptionA code from a preconstructed deck gives you that same deck digitally, containing the same cards. That contrast is the thing to remember: a deck code gives you the same cards, a pack code does not.
  • Bigger boxes vary, and they changed in 2025The packs inside an Elite Trainer Box each carry their own code, and the box's own code might be packs, a promo card, currency or cosmetics. Pokemon widened that list in July 2025 and said plainly that contents vary by product, which is why there is no product-by-product table here.
  • You never have to guessEnter a code and the app names what you are about to receive before you claim it, and how many codes you have already redeemed for that product. Read the screen first.
  • One code, one time, one accountA code works once, ever, and it stays on the account you entered it into. Pokemon allows one account per person and says it cannot transfer cards or decks between them.
  • Old code cards are worth tryingPokemon publishes no expiry date for pack codes and nothing official says they run out. That is not a promise that they never will, but a shoebox of old ones is worth an evening. Campaign codes are a different thing and do carry end dates.
  • There is a soft limit, and it is highPast 400 booster codes from one expansion, further codes from it pay out a little in-game currency instead of a pack. Most people never get near it; if you open cases on camera, it is closer than it sounds.

How many have come out of our packs?

Every rip here gets its packs counted, and a code card comes in every one, so counting packs counts code cards. The answer is 400, across 303 filmed openings. The counting is not for this page: it is where every kind of sealed product we have opened gets its numbers.

  • English packs onlyThe 65 Japanese, Korean and Chinese packs opened here are held out. Pokemon says nothing either way about whether a non-English pack carries a code the English app takes, and the smaller honest number beats one that quietly picked an answer.
  • It is a floor, not a totalOnly the openings where somebody wrote the count down are in it, so the real figure is higher.
  • Not one set, 26 of themA booster code gives a digital pack of the expansion it came out of, and these came from 26 different English expansions.
  • Still nowhere near that soft limitThe biggest single pile counted here is 71 packs of Ascended Heroes, against the 400 above. If a channel that opens this much is not close, you are not close.

How to redeem one

Two routes, and they do the same job. Use whichever is in front of you.

In the app

  1. Open the Shop.
  2. Select Redeem.
  3. Type the code, or scan the QR square with a webcam.
  4. Check each item, then select Claim Now.

On the web, faster for a stack

  1. Go to redeem.tcg.pokemon.com.
  2. Log in to the account you use for TCG Live.
  3. Enter the code and select Submit Code.
  4. Select Claim Now.
  • It did not fail, it went to your InboxSome rewards land straight in your collection. Others, booster packs included, go to the Inbox under the Menu. That is where people decide a code did not work.
  • Check whose account you are in firstBeing logged in on pokemon.com is not the same as being logged in here, and Pokemon says you may have to log in again on the TCG Live site.
  • If Redeem is not in the app on your phone, use the websiteIt works from any browser on any device and does exactly the same job.
  • Do not throw the card away until the reward has landedSupport asks for the code number, the screen name you redeemed to, and where you tried it, and says a claim without that information may be dismissed. If you are filming an opening, that is a floor covered in little cards and no way to prove anything about them.

Getting the app

Four platforms: iPhone and iPad, Android, Windows and Mac. There is no play-in-a-browser version, so you are downloading an app. The only thing you do on the web is redeem codes.

Pokémon TCG Live is the one you want, and it is free.

Two things most guides skip. The Windows and Mac versions are direct downloads from Pokemon's own site rather than store apps, so hunting the Microsoft Store or the Mac App Store will not turn them up. And you need a free Pokemon account: the support site now calls it a Pokemon Trainer Central account and older material calls it a Pokemon Trainer Club account. Same account.

For a younger player, a parent makes the account first and creates a child account under it, which strips out the ads and the links off to other sites and ages up on its own.

You want a broadband connection and around 3GB free. The floors are Windows 10, macOS Monterey 12, iOS 15, Android 9, as of April 21, 2026, when Pokemon last raised the iPhone and Mac ones. They go up over time, so an old phone can stop being supported. It runs across most of the world: if your app store has it, you can play.

Same rules. Everything around them is different.

The rules are the rules. If you have never played at all, read those first. Everything below is only what changes when the game is software instead of cardboard.

  • It teaches you, then it enforces the rulesThe Learn tab holds the Learning Lab: guided lessons against the computer, replayable in any order. Conceding one costs you nothing, not your level and not your ranked win streak.
  • You start with decks already builtA handful of ready-made decks come with the account, so your first real game is five minutes away.
  • You do not need luck to own a cardThe one nobody expects. You spend Trade Credits in the deck editor, pick the card and the version you want, and it is yours. It is final and not refundable, so spend them on what a deck actually needs.
  • Duplicates are not wastePast the four copies you may hold, extras turn themselves into Trade Credits. A fifth copy is not a dud, it is progress toward the card you want, the opposite of how opening cardboard feels. Trainer Points, the other currency, come from quests and leveling up and buy packs.
  • Rarity is cosmetic hereThe same card exists in several finishes and you pick one. The fancy print plays identically, which is the point our rarity guide makes about cardboard.
  • A free Battle Pass every setEach expansion brings one, unlocked by playing, paying out packs, decks and cosmetics at no cost.
  • No chatNo text or voice chat at all. A few preset reactions during a game and nothing else.
  • Standard, and Expanded with gapsExpanded reaches further back and never rotates, but Live does not support every Expanded card: in an article last edited in July 2026, Pokemon said phased support for more was expected during 2026.

There are two free official apps

Live is the card game itself, digitally: the same rules, the same 60 card decks, and a use for the code cards out of your packs. Pocket is a smaller, faster game of its own on a phone, with free packs every day and nothing at all to do with those codes. The sharpest practical difference is the third row. Live wants a free Pokemon account before you play; Pocket never asks you for one. Both are official, both are free, and installing both costs nothing.

Tips for your first week

  1. Redeem your codes before you spend anything. They cost nothing and they are the fastest collection you will ever build.
  2. Check which account you are in before you start typing. Scattering codes across two accounts is the one mistake nobody can undo for you.
  3. Play the starter decks first. They are complete, legal decks. Building can wait a week.
  4. Spend Trade Credits on what a deck needs, not on the pretty version. Pokemon's own warning is that exchanging is final and not refundable, and the special version plays the same.
  5. Let the duplicates pile up. They convert themselves and they are paying for your next card.
  6. Use the Learning Lab even if you know the rules. It is the cheapest way to find out where the buttons are, and quitting one costs you nothing.
  7. Read the screen before you claim. It tells you what the code gives you and how many of that product you have redeemed already.

Ranked play exists. It runs in monthly seasons through a set of leagues, and the top of it is the Arceus League. Pokemon documents almost none of the rest publicly, so this page is not going to print point values it cannot stand behind.

Does any of it actually mean anything?

Nothing comes back. There is no path from a digital collection to a card you can hold, and no trading in Live at all: Pokemon says players cannot trade cards with each other. It is not a catalog of what you own in real life either. Pokemon had an app for that, Card Dex, and shut it down on September 20, 2023 with no way to export the data.

And nothing in it is worth money. Pokemon's terms say virtual content has no monetary value and may not be redeemed for currency or anything of value outside the game. Take that at face value.

Which leaves the question this audience asks, about selling unused code cards. What is verifiable: a redeemed code is dead, so the only sellable one is a code nobody has entered, and Pokemon's terms restrict transferring or reselling virtual content in ways they have not permitted. Whether that covers cardboard in your hand is a legal question, and we are a Pokemon channel rather than a law firm.

So the honest pitch is the one at the top. The code card is the only thing in a booster pack with no collector value at all, and this is what it is for. When you would rather play a person than a screen, the shops around Rochester run league nights.

The code card questions, answered short

What is the code card in a Pokemon booster pack?

It is the card in the pack that is not a Pokemon card. It carries a code for Pokemon TCG Live, the free official digital version of the card game, and the code gives you a digital booster pack from the same set.

Does the code give me the cards I just pulled?

No. Pokemon says the digital booster pack will not necessarily contain the same cards as the physical pack the code came from. It is its own pack from the same set. A preconstructed deck code is different: that one gives you the same deck with the same cards.

How do I redeem a Pokemon TCG Live code?

Two ways. In the app, go to the Shop, choose Redeem, type the code or scan the QR square, check each item and select Claim Now. Or go to Pokemon's redemption site, log in to the account you use for TCG Live, enter the code and claim it there.

Do Pokemon code cards expire?

Pokemon publishes no expiry date for booster pack codes and nothing official says they run out, so an old code card is worth trying. Promotional codes from campaigns are a different thing and those do have end dates.

Is Pokemon TCG Live free?

Yes. It is free on iPhone, iPad, Android, Windows and Mac, and you need a free Pokemon account to play. There are optional purchases and they are cosmetics and shortcuts rather than a way in.
