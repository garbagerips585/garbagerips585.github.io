What set is my card from?

The card already tells you, twice. There is a number at the bottom that reads something like 45/102, and a small symbol next to it. Type the number after the slash and this page will tell you which sets were printed at that size, with the symbol for each one so you can finish the job by eye.

No English set was printed at that size. Two things it is usually: a promo card, which is numbered inside a running promo series rather than out of a set, or a Japanese card, whose sets are sized differently and are not in this index. Try the full set list or the card search.

Where to look

The corner moved in 2017

Both the number and the symbol sit in the same bottom corner, and which corner that is depends on how old the card is. This trips people up because most guides get the date wrong.

  • Bottom right on cards up to the XY era. If the number and the symbol are on the right, you are holding something from 2016 or earlier.
  • Bottom left from Sun and Moon onward. The move happened in 2017, not at Scarlet and Violet, which is what you will usually be told. Our rarity guide shows both corners magnified on real cards.
  • The symbol is the tiebreaker, not the number. Of the 86 different set sizes in this index, 48 belong to exactly one set and 38 are shared by two or more. Every card printed at 132 could be from 4 different sets: Gym Heroes (2000), Gym Challenge (2000), Secret Wonders (2007), Mega Evolution (2025). The symbols are not alike, so once the number has narrowed it the picture finishes it.

If the left number is bigger

A card numbered above its own set total is not a misprint and it is not fake. It is a secret rare, printed deliberately past the end of the checklist, and it is usually the reason anybody was opening the packs.

So the number after the slash still identifies the set even on a secret rare: Paldean Fates cards all read out of 91 whether they are card 12 or card 245. Rows in the index above carry a badge saying how far past the printed total each set runs. What those cards are actually called is on the rarity guide, and what they are worth is on card search.

When the number will not do it

Three cards this will not find

  • Promo cards. 33 of the 174 English sets in our data are promo runs, Black Star series, tins, trainer kits and tie-ins. Their cards are numbered inside the promo series rather than out of a set size, so there is often no slash at all. They are not in the index above for that reason. The full set list has all 174, promos included.
  • Japanese, Korean and Chinese cards. Different sets, different sizes, and a number that will either miss or match an English set it has nothing to do with. If the text is not in English, start from the set guides, which include 23 full guides and several imported sets.
  • Cards with the number rubbed off. It happens on played vintage. The symbol survives longer than the print does, so work from that and from the copyright line instead. If you are checking a card because something about it feels wrong, the real or fake checks are the better page.

Where this came from

  • Set names, sizes, symbols and release dates. The Pokemon TCG API, synced August 11, 2026. The size used here is the API's printed total, which is the number printed on the card, not the number of cards that exist.
  • Secret rare counts. Counted from the full checklists this site holds for 23 sets, as the difference between how many cards a set has and the total printed on them.
  • The symbols. Served from the API's own image host and shown at the size they are published at. They are small on the card too: a phone camera and a pinch zoom is the normal way to read one.
  • Nothing here is estimated. Every number on this page is counted from that list when the page is built, so it cannot drift from the index printed above it.
