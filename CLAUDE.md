# Garbage Rips 585: brand hub site

This file is the index. It holds every live rule in one line with its reason and a pointer. The detail, the
measurements and the history live under `docs/` and are read on demand. Paths are written as plain text on
purpose: do not turn them into imports, which would load everything again.

**Before touching an area, read its doc (see "Read before touching" at the end).** The docs record why many
odd-looking things in the code are deliberate. If a rule here and the code disagree, check the code and the
built tree, then fix whichever is wrong in the same commit.

## What the site is

A content hub and SEO home for Garbage Rips 585, a Pokemon card pack-ripping channel from Rochester, NY, run by
one person (the owner, who is not a developer). It is not a store. The job is brand entity SEO and sending
visitors to the channel and socials. The site is live at garbagerips.com (`LIVE = true` in shared/site.mjs).

## Build, verify, commit (docs/build-and-verify.md)

1. `git pull` before editing. The nightly commits to main and can land hours late.
2. Edit source only: `scripts/`, `shared/`, `assets-source/`, `data/`.
3. `GR_SKIP_IMAGE_BUILDERS=1 TZ=America/New_York node scripts/build-all.mjs` must end "N of N builders ok".
4. `python3 scripts/check-build.py` must end "all checks pass". Exit 1 is a broken build. Exit 2 means the
   build is fine and a workbook cell needs the owner: report it, do not patch data/hits.json.
5. Before committing `public/`: `GR_SKIP_IMAGE_BUILDERS=1 TZ=America/New_York node scripts/check-tree-drift.mjs --staged`.
   Both variables are required or it reports false drift from image bytes and the calendar.
6. `TZ=America/New_York node scripts/check-freshness.mjs` tells you whether the nightly's data is still moving.
7. Commit source and `public/` together, staged by explicit path.

Rules:
- **Always finish with build-all.mjs.** A single builder run afterwards, even one run only to read its output, breaks the tree (inline CSS comments come back and the page-CSS split is undone). (docs/css.md)
- **Never `git add -A` or `-u` while agents are editing.** It commits their half-finished work. (docs/build-and-verify.md)
- **Commit source and `public/` in one commit.** A builder change without its pages ships a stale site and passes every local check. (docs/build-and-verify.md)
- **Never run a `sync-*` or `refresh-*` script unless that is the task.** They call other people's servers and rewrite data; several are hand-run on purpose and are not in build-all. (docs/build-and-verify.md)
- **Do not write page, builder or video counts as constants** in this file or the docs. Read them from the build output or `node scripts/build-untagged.mjs`. (docs/build-and-verify.md)
- **Measure, do not reason.** Quote a before/after pair or neither, say which DPR and whether it is on-load or fully scrolled, serve gzipped, and take a same-tree noise floor first. (docs/card-images.md, docs/css.md)
- **Verify in headless Chrome over CDP**, a fresh profile per run, at 390x844 and 1440x900 at least. (docs/build-and-verify.md)
- Local preview: `node .claude/server.js` on port 4585 where `.claude/` exists; any static server on `public/` otherwise. (docs/build-and-verify.md)

## Copy

- American English only. Nobody says "dearest"; say "most valuable". (docs/pages/topps.md)
- No em dashes in written copy. Natural, human tone; the voice is fun, chaotic, zero gatekeeping. (docs/brand.md)
- Always "Rochester, NY", never bare "Rochester", in visible copy. Rochester references are welcome: Garbage Plate, 585, Wegmans, Trubbish. (docs/brand.md)
- The footer must keep "Fan content. Not affiliated with The Pokemon Company". Card and sticker illustrations are by Unableplacebo. (docs/brand.md)
- Fonts: Titan One (display), Outfit (body), Space Mono (labels). A new `font-weight` can fetch a whole extra font file; check the weights already on the page. (docs/gotchas.md)
- Page titles carry no "| Garbage Rips 585" suffix on most families. Do not restore it; `og:site_name` carries the brand. Meta descriptions were deliberately not trimmed. (docs/page-titles.md)
- Never state a fact the data files do not hold: no guessed address, ZIP, date, hour or price. (docs/owner-facts.md)
- A statement that something "does not exist" must name what was LOOKED AT, not what exists. That error was made three times on one page. (docs/pages/garbage-plate.md)

## Color: the accent rule (docs/brand.md)

- **Teal is how you get around, pink is what the site is saying, and a body section heading is neither** (off-white), so the two accents never land on each other.
- Teal: every link, button fill, hover and current-page state. Pink: marks that go nowhere (highlighted word, RIPS in the wordmark, NEW and #1 HIT flags, prices).
- Small text needs 4.5:1. Small pink is `--ketchup-deep`, small teal is `--sky-deep`. The big pink is NOT "large text" under 24px.
- Never invent a hex. Read the token from `:root` in assets-source/ui.css, where each derivation is written beside it. Token NAMES do not mean their colors ("gold" and "mustard" tokens are teal).
- `--paper-3` is the LIGHTEST surface now; a small accent on it fails contrast. Use `--paper` or a dark fill.
- Gold is semantic, not palette: Hall of Fame badge, trophy frame and rank medallion only, as literal hexes.
- Never write a surface token where ink belongs or the reverse. Grep both directions before touching a color.
- Pack art, card scans and product photos are content. Never tint one to match a repaint.
- The share cards are painted in Python. `scripts/build-og.py` is NOT in build-all; a palette change must run it by hand along with build-og-pages.py.

## CSS (docs/css.md)

- **Edit `assets-source/ui.css`, never `public/assets/ui.css`** (generated by scripts/build-css.mjs; check-build fails on drift).
- Rip-only rules and the eight pack keyframes live in assets-source/pack-rip.css and build into public/assets/packs.css. Run build-css.mjs after any hand run of build-packs.py.
- Page-only rules are moved out of ui.css into each page by scripts/split-page-css.mjs on every build. Keep editing the one source file.
- **A class added only by JavaScript must appear by its full literal name** in a file under assets-source/js/ (or the builder's inline script), or the splitter can drop its rules. Never build class names by concatenation.
- Comments in ui.css and in inline `<style>` source are stripped at build. They record measurements; write more, do not tidy them.
- Do NOT delete rules because coverage says they are unused. Coverage cannot see hover, focus, print, media or JS-toggled rules.
- ui.css is the one render-blocking request on every page: a kilobyte there costs more than anywhere else. Page weight buys nothing on a cold load and real time on every later page; quote both.
- If a page-level rule does nothing, look for a longer selector in ui.css first (`.set-hero .wrap` is the known one). (docs/pages/topps.md)
- In builders: a backslash in emitted JS must be doubled, and never put a backtick inside a template literal's text. Run the builder; `node --check` can pass a broken one. (docs/build-and-verify.md)

## Links (docs/links.md)

- **Every video tile and video link goes to that video's own /rip/ page on this site, never to youtube.com.** scripts/build-pages.mjs writes a page for every video so no tile dead-ends.
- **The only outbound YouTube link is Subscribe**: `SUBSCRIBE` and `SUB_LABEL` from shared/chrome.mjs, `rel="noopener" target="_blank"`, an aria-label that says it opens YouTube, class `.btn-sub`.
- Since 11 November 2026 Subscribe also appears in the `.pitch` block on rip pages and set guides (shared/channel-pitch.mjs) and as the last action on the end card. The pitch line may only repeat the footer's claim or a fact the builder can check. No other family gained one.
- **The outbound test: does the READER need the destination, or does the SOURCE deserve a credit?** The first earns a link. The second earns a name in plain text.
- **The required shape for any outbound link:** at the end of a row or page, never mid explanation; a small labeled control beside larger internal ones; aria-label ending ", opens on <host>"; `rel="noopener"`; `target="_blank"`.
- The link follows the price: a row links to the source its printed figure came from. If the source changes, the link changes in the same edit.
- If an outbound link is arguable, write the argument in docs/links.md in the same commit. Do not add one quietly, and do not keep a count of exceptions.
- License credits are not optional: CC BY and CC BY-SA photos and OpenStreetMap data need a visible credit with links. Copy `photoFig` in build-garbage-plate.mjs. No raster map tiles. (docs/card-images.md, docs/links.md)
- Never link, quote or summarize the digital games' drop-rate pages from /how-to-play.html, /tcg-live.html or /tcg-pocket.html; that needs the owner's separate call.
- /top-graded.html and /topps-card-values.html print the source path as plain text with no row links; that is an open owner call, not an oversight.
- A playlist with zero videos does not render.

## Video and the pack player (docs/pack-wrapper.md, docs/video.md)

- Never put live iframes in a grid. Tiles are a click-to-load facade and only one player is live at a time.
- The embed mounts MUTED, waits for the player to report playing, then unmutes. Do not change the order.
- The end card is one tap, not autoplay: auto-advance would land the next rip muted. NEXT PACK is never dropped; where there is no next, there is no control. Subscribe sits last on it.
- The reveal is driven by `animationend` on `tearL`, not timers. Change pack art size by moving the face, never by `background-size`.
- The end card is sized off the PLAYER, not the viewport. Read `data-dur` and `data-views`, not tile text.
- Grid tiles are 2:3, the player opens at 9:16, columns are 6 / 4 / 3 / 2. Thumbnails use the `oardefault` variant.
- A rip rail differentiates by what was OPENED, never by what came out. Rails round-robin by product kind and spin the window per page; do not "simplify" either.
- Tags come from shared/taxonomy.mjs; hand corrections go in data/overrides.json and always win. `pulls` comes from the rip log's Hit Card cell, not the title.
- When testing packs, use a fresh browser per page: after about five pages the accumulated embeds starve the renderer and produce false failures.
- "N rips" links to the filtered list; "1 rip" links straight to that rip. Retailer pages and minigames deliberately carry no video.

## Data the owner supplies (docs/owner-facts.md)

- **MSRP comes only from the owner's manual Pokemon Center reads.** pokemoncenter.com is bot gated; no script may touch it and nothing may be estimated.
- **Pack numbers and hits come only from the owner's words**, or from a video description when he authorizes it. Write them to data/overrides.json and data/hits.json BEFORE running scripts/sync-youtube.mjs.
- Workbook rows are fixed in the workbook and re-imported; do not hand-edit workbook-derived rows in data/hits.json. (docs/video.md)
- **Card shows: the owner confirms every show.** Never guess an address, ZIP, date or hour. Shop hours print only where the business states them about itself, with source and read date. (docs/shows-shops.md)
- `SHOW_PAGES_SINCE` in shared/show-pages.mjs must not move forward; it would un-build pages people saved. (docs/shows-shops.md)

## Prices, pull rates, printings (docs/set-pages.md)

- **Pull rates are a sourcing rule: state one only if the publisher confirmed it** (TPCi, Pokemon Center, pokemon.com, printed odds). An opened box is a sample, not a rate. A leak, another region or another product is not confirmed. Prefer a guarantee to a rate. /luck.html stays labeled as the channel's own observed results.
- One price source per page. Raw prices are PriceCharting's (overlaid in sync-cards.mjs); do not add a second feed to a page that has one. Use `priceNote(doc)` from shared/card-prices.mjs for the date wording.
- PSA 10 figures come through shared/graded-price.mjs and nowhere else. Do not delete its fallback or its printing check.
- Nothing from PriceCharting is published on a single read; the ranked lists go through shared/graded-gate.mjs.
- Between data/graded.json and a card file for one printing, the newer read wins and a tie goes to graded.json (`newerRead()` in shared/graded-price.mjs). Do not put either permanently in front.
- A ranked list's `checked` is its oldest listing read, not the day the weekly job ran; `verify.ran` is the re-read day. Do not "correct" it to today. (docs/nightly-and-deploy.md)
- The standard-printing allowlist in sync-pricecharting-cards.mjs is load bearing.
- **A logged hit's printing is decided by the rarity the owner typed**, then an explicit number, and the dearest printing only as a last resort. If a resolver change moves the rarity mix, it is wrong.
- "Mega Attack Rare" is folded to Ultra Rare at ingestion in scripts/sync-cards.mjs (matching import-sheet.mjs). Do not add a rung for it without the owner.
- A set TCGdex has not published uses the pending path (`tcgplayerPending`, `PENDING_META`, derived scan pins). Retire all three together when TCGdex carries the set.
- A card-shots pin is added only after the TCGdex url was checked and 404'd. `rawNm` is the price of last resort and must stay last.
- Deck .txt files are verbatim Limitless exports; never prepend anything. "Best deck" is never claimed. (docs/pages/decks.md)
- Topps: do not edit an `expect` block to make a build pass; nothing may sort by `rank`. (docs/pages/topps.md)

## Images (docs/card-images.md)

- **Check every `sizes` at DPR 3, not DPR 2**, and read `currentSrc`, never the markup or `naturalWidth`. It is the rung that decides, not the box. Leave real headroom.
- Use `productSrcset()`, `imgDims()` and `avifPicture()` from shared/format.mjs; never hand-write a srcset or dimensions. The four scan hosts do not behave alike.
- `loading="lazy"` is a vertical heuristic: carousel slides must stay deferred behind `data-packsrc`, and a deferred slide's `<source>` must be deferred too.
- A CSS background cannot be lazy. An LCP image wants eager plus a preload; a decorative thumbnail in the first viewport is often better left lazy. Measure over HTTP/2.
- Do not add a 700w pack rendition, do not put `_in_1000x1000.jpg` back on a ladder, do not "fix" /rarity.html's ladder cards or /topps-card-values.html's scans.
- Builders skip scans listed in data/no-scan.json. `sweep-scans.mjs` reads the built tree and is not in build-all.
- Garbage Plate photos: never crop (license), every one lazy including the hero, `maxw` is a placement cap. (docs/pages/garbage-plate.md)

## Layout and accessibility checks

- **The overflow test:** an element whose right edge is past `documentElement.clientWidth` with no clipping ancestor. Not `innerWidth`, not `scrollWidth`, not `scrollX`. Check 320, 390, 768 and 1440. (docs/video.md)
- A grid item's minimum is its min-content width; use `minmax(0,1fr)` or `min-width:0`. (docs/pages/topps.md)
- One h1 per page, headings in order, an aria-label on every new nav landmark. (docs/build-and-verify.md)
- Tap targets at least 44px tall on phones for standalone links and buttons; measure the box, a flex child can be smaller than it looks. (docs/build-and-verify.md)
- Honor `prefers-reduced-motion`: the blanket rule, the pack rule, and hover transforms only under `no-preference`. (docs/gotchas.md)
- Color carries none of the meaning in a diagram; words in a scaled SVG belong in HTML. (docs/pages/garbage-plate.md)

## Home page (docs/home-page.md)

- If you change the home page, update docs/home-page.md in the same commit. Stale layout notes get quoted back as constraints.
- Every video band plays IN PLACE; the tile is still an `<a>` and the handler stops the navigation.
- On a phone (under 545px) both shelves are swipe rows of two tiles and part of a third, and Latest rips sits under Greatest Hits by CSS `order`. The tile and its stage are both 9:16.
- `main:has(>.hof)` scopes that phone layout to the home page, because six other pages slice index.html's head.
- The drops band expires rows at build and again in the browser, and removes itself when empty. Never truncate a row; the hedge is the end of the sentence.
- The trophy banner's bottom edge must clear 700px at 390 wide (Safari chrome), not 844.
- Do not "simplify" the fractional slide counts, reinstate a single centered card, or make the trophy bigger to win LCP.
- Relative dates are recomputed in the browser; the newest rip's label is derived from its publish date.
- Do not overlay copy on the banner art.

## Sharpest gotchas

- A media query sizes the viewport, not your box. Size a component off its container. (docs/pack-wrapper.md)
- `offsetParent` does not prove an element is reachable; a slide off the track passes it. (docs/pack-wrapper.md)
- `getComputedStyle` resolves `url()` to absolute, so two trees on two ports differ on every background. Normalize the origin. (docs/css.md)
- `gzip -9c file` and `gzip -9c < file` give different sizes. Measure from HEAD, not a tree an agent is editing. (docs/css.md)
- An off-screen background arrives seconds after load; wait for the network to go quiet before believing a saving. (docs/card-images.md)
- Chrome reuses a `--user-data-dir` and serves the old asset at the same `?v=` url. Unique profile, cache off. (docs/home-page.md)
- A 404 check is not a scan check: PriceCharting's CDN answers 403, and a relative placeholder url makes `fetch()` throw. (docs/pages/topps.md)
- A fallback tile cannot tell "no file" from "no alias". Check data/brand-marks.json before believing one. (docs/home-page.md)
- EXIF orientation must be applied when resizing photos. Flickr license filters must include 11 and 12. (docs/pages/garbage-plate.md)
- A hand-typed list of exceptions or a count goes stale the first time somebody adds a page. Compute it or name the rule. (docs/links.md)

## The nightly (docs/nightly-and-deploy.md)

- `.github/workflows/refresh.yml` runs at about 3am New York time (two UTC crons, one skips), with `TZ: America/New_York`, syncs, rebuilds with build-all, checks, and commits. pages.yml then deploys `public/` only.
- It can arrive up to about three hours late. Pull before editing.
- A failed night comments on one GitHub issue titled "Nightly refresh is not healthy"; a clean night closes it.
- `.github/workflows/weekly-prices.yml` ("Weekly price lists", Sundays) owns data/graded.json, the three ranked lists, First Partner prices and data/price-history/; it shares the nightly's lock, saves no cache and adds no crawl. (RUNBOOK.md, docs/nightly-and-deploy.md)
- Check it: `gh issue list --search "Nightly refresh is not healthy"`, `gh run list --workflow=refresh.yml --limit 5`, and `TZ=America/New_York node scripts/check-freshness.mjs`.
- `paginate()` in scripts/sync-youtube.mjs stops on an empty page, a repeated token or 200 pages. All three are load bearing; an endless loop there burned the API quota from 4 to 8 November 2026. (docs/video.md)
- The custom domain is set in GitHub Settings, Pages. `public/CNAME` is a record of intent, not the switch.
- DEPLOY.md is the operating document for deploys, and RUNBOOK.md for incidents where it exists. This file does not repeat them.
