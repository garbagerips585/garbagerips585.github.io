Photos of the REAL retail booster packs, one per set, named by set id:

    pitch-black.jpg
    chaos-rising.jpg
    prismatic-evolutions.jpg

These must be photos you took of packs you own. Official product photography
is not ours to copy, which is why this folder starts empty.

Shoot the pack flat against a plain background, roughly 2:3 (taller than wide).
Anything from a phone is fine; the build resizes to 720x1080 WebP.

Then run:  python3 scripts/build-packs.py

A set with no photo simply hides that panel on its set page.
